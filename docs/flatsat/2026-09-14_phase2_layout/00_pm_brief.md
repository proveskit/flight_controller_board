## 4. Hard rules

1. Never modify `FC_V5e_Production_Rev2/` (GUI open). Never open the KiCad GUI on `FlatSat_V1`. Never `git commit`.
2. **One writable board at a time.** The live board is `FlatSat_V1/FlatSat_V1.kicad_pcb`. Every agent works on a copy in its own scratch directory, proves the result (heritage 0, DRC delta, parity), and only the stage owner named in the workflow copies the result back — atomically (`.tmp` + `mv`). Agents never edit the live board concurrently.
3. Only pcbnew scripting (`/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3`) and `kicad-cli` touch the board. Save with `pcbnew.SaveBoard`.
4. Heritage check must pass at every hand-back (L4). A stage that cannot pass it stops and reports; it does not "fix" heritage.
5. Schematic files change only in the supply-chain stage (LCSC/Datasheet fields) and only via each sheet's generator + regenerate, or a field-only edit mirrored into the generator; ERC/netlist must remain identical otherwise (`tools/netlist_diff.py` against the Phase-1 final netlist shows only field changes, no net changes).
6. Nothing in series with a flight power path (Phase-1 rule 6) — layout cannot add parts, but it can add copper: no new copper may join two existing FC nets.
6a. **L11 attachment rule:** no new track or via inside the Rev2 outline except a compliant stub from an allowed pad (connector pad, or R104/R100/R103 for the EN taps) to the extension; `tools/pcb/attachment_check.py` must report 0 violations at every hand-back from the routing stage on. The autorouter runs with the flight section keyed out (`route.sh` adds the keep-out from `tools/pcb/fc_keepout.json` to the DSN export copy only).
7. RF/keep-outs per §2 (U13→RF1 trace, U30 surroundings).
8. `jlcpcb/project.db`: read-only for agents.
9. Placement outside the outline is a defect at hand-back (the staging grid is temporary).

## 8. Deliverables per stage agent

A stage returns (structured): board copy path, DRC counts (errors/unconnected/parity, new-only), heritage result, what changed (counts), open issues; and writes its markdown report into `docs/flatsat/2026-09-14_phase2_layout/`. Hand-back to the live board is done by the workflow's integrator step only after the checks pass.

## 9. Exit criteria

DRC: 0 errors, 0 unconnected, parity limited to §6, warnings triaged. Heritage: 0 violations. Every new part inside the outline with L3 lanes and §2 keep-outs respected. Netclasses per L5 applied and visible in DRC (no width below class). Supply chain: every new part has an LCSC number or a documented "no LCSC (test point / DNP)" status. Review: `pcb-flight-review` run, `fix-this-rev` items closed, the rest listed as deferred with rationale. Preview production files generated. Then the owner does the JLCPCB-plugin GUI steps and orders (Phase 3).
